👉 [Try it Live Here](https://universal-translator-summar.streamlit.app/)

## ✨ Features
- ✅ 30+ World Languages Support
- ✅ RTL & LTR Script Support (Urdu, Arabic, Persian)
- ✅ Bulk Translation
- ✅ PDF & Word File Translation
- ✅ Image & Camera Text Extraction
- ✅ Text to Speech
- ✅ Translation History

## 🛠️ Tech Stack
| Technology | Purpose |
|------------|---------|
| Python | Core Language |
| Streamlit | Frontend UI |
| Groq AI | AI Engine |
| LLaMA 3.3 70B | Translation Model |

## ⚙️ Installation
\`\`\`bash
git clone https://github.com/SummarRajpoot/universal-translator-agent
cd universal-translator-agent
pip install -r requirements.txt
streamlit run app.py
\`\`\`
